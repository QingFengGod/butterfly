# butterfly
这是一个butterfly集合，包含utils，template（正在开发）和butterfly-desktop-application（未开发）

# butterfly-desktop-application
butterfly-desktop-application是一个桌面应用，无需登陆，支持html+css+js打包为bf格式的应用，对您的代码加密，并在butterfly-desktop-application上运行，数据存储在自己电脑上，保证数据安全不经过服务器，可以自己手动将数据备份在服务器上，备份时将会生成一个id，需要自己保存这个id，以便到时对服务器上备份的数据进行操作，也可以支持自定义服务器，需要在服务器上安装server应用，到时并会集成一些内置应用，包括（个人安全的密码箱应用，个人的nav应用，代码片段记录器应用，代码生成器应用，电影仓库应用等）
